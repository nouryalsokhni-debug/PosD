# **١. نظرة عامة**

## **مكوّنات النظام**

| **المكوّن**                     | **الوظيفة**                                                                                                               |
|--------------------------------|---------------------------------------------------------------------------------------------------------------------------|
| **تطبيق نقطة البيع (الكاشير)** | شاشة البيع الرئيسية. أكثر من نقطة بيع في الفرع الواحد تعمل على المخزون والطلبات نفسها، ولكل نقطة وردية ودرج مستقلان.      |
| **شاشة الزبون**                | تعرض الأصناف والمبلغ أثناء البيع.                                                                                         |
| **لوحة التحكم المركزية**       | إدارة الكتالوج والأسعار والعروض والمشتريات وسعر الصرف والمخزون والصلاحيات والتقارير والإعدادات - لكل الفروع من مكان واحد. |

## **أساسيات المنصة**

| **الأساس**                     | **الوصف**                                                                                       | **المرجع**     |
|--------------------------------|-------------------------------------------------------------------------------------------------|----------------|
| **تعدد العملاء**               | عزل تام لبيانات كل عميل على المنصة نفسها.                                                       | GEN-01         |
| **تعدد الفروع والنقاط**        | إضافة فرع أو نقطة بيع إجراء إداري لا يتطلب تعديلاً برمجياً.                                       | GEN-02         |
| **واجهة بلغتين**               | عربي وإنكليزي، بتبديل فوري من داخل الواجهة.                                                     | GEN-03         |
| **تجربة استخدام قابلة للقياس** | بيع نموذجي بثلاث لمسات كحد أقصى؛ تدريب موظف جديد خلال ثلاثين دقيقة؛ شاشة بيع بشبكة أصناف مصوّرة. | GEN-05، CAT-05 |
| **عمل كامل دون إنترنت**        | كل الخطوات التشغيلية تعمل محلياً وتتزامن عند عودة الاتصال.                                       | OFF-01         |

# **٢. المستخدمون والصلاحيات**

## **الأدوار**

| **الدور**            | **النطاق**                                                                   |
|----------------------|------------------------------------------------------------------------------|
| **كاشير**            | البيع اليومي على نقطة البيع، والإرجاع الموثّق، وإغلاق ورديته.                 |
| **باريستا**          | تحضير الطلبات وفق قسائم التحضير.                                             |
| **مدير فرع**         | الإشراف التشغيلي داخل الفرع: الاعتمادات، الجرد، الإلغاءات، فتح الدرج المسبَّب. |
| **محاسب**            | المراجعة المالية والتقارير.                                                  |
| **مالك**             | اطلاع كامل على التقارير والأداء.                                             |
| **الإدارة المركزية** | إدارة المنصة من لوحة التحكم: الكتالوج والأسعار والمشتريات والإعدادات.        |

*الأدوار قابلة للضبط، ومصفوفة الصلاحيات قابلة للتعديل بحيث تُربط كل عملية حساسة بدور (USR-01، USR-02).*

## **ضوابط الاستخدام**

| **الخطوة**           | **الإجراء**                                                | **المرجع** |
|----------------------|------------------------------------------------------------|------------|
| **دخول ببطاقة**      | بطاقة موظف بديلاً عن كلمة السر لتسريع العمل.                | USR-03     |
| **تسجيل المنفّذ**     | اسم الموظف على كل عملية حساسة: إلغاء، خصم، إرجاع، فتح درج. | USR-04     |
| **سجل تدقيق**        | غير قابل للتعديل - لا حذف ولا تغيير لقيد بعد إنشائه.       | USR-05     |
| **تعدد الفروع**      | يمكن ربط الموظف نفسه بأكثر من فرع.                         | USR-06     |
| **استهلاك الموظفين** | تسجيل الاستهلاك والضيافة بسعر صفر ضمن حد يومي مضبوط.       | USR-07     |

## **توزيع الصلاحيات المعتمد**

| **العملية**              | **الجهة**                                | **الحالة**           |
|--------------------------|------------------------------------------|----------------------|
| حذف صنف قبل الدفع        | الكاشير                                  | مؤكد                 |
| إلغاء فاتورة بعد الدفع   | مدير الفرع                               | مؤكد                 |
| إرجاع نقود               | الكاشير - يفتح الدرج ضمن العملية الموثّقة | مؤكد                 |
| فتح درج النقود دون عملية | مدير الفرع - مع تسجيل السبب              | مؤكد                 |
| إغلاق الوردية            | الكاشير                                  | مؤكد                 |
| جرد الصندوق عند الإغلاق  | مدير الفرع                               | مؤكد                 |
| تعديل سعر صنف            | الإدارة المركزية                         | مؤكد                 |
| الاطلاع على التقارير     | الإدارة ومدير الفرع                      | مؤكد                 |
| منح الخصم اليدوي         | مدير الفرع - ضمن سقف يُضبط مركزياً         | افتراضي قابل للتعديل |

**آلية الدرج:** البيع والإرجاع يفتحان الدرج تلقائياً ضمن العملية الموثّقة باسم المنفّذ؛ فتح الدرج دون عملية محصور بمدير الفرع مع سبب مسجّل. بذلك يؤدي الكاشير كامل عمله دون صلاحية فتح حر للدرج.
