# FLOW-06 Back office operations

| Area | Action | Ref |
|---|---|---|
| Catalogue | Central edit applied to all or selected branches; Excel import | CAT-01, CAT-07 |
| Prices | Central only, full change history | PRC-02, PRC-03 |
| Purchasing & stock | Supplier purchases, goods-in to branches, reorder alerts, stock count, waste | STK-04 → STK-09 |
| Exchange rate | Daily entry, applies to all branches, fixed on invoices | PAY-04 |
| Promotions | Combo, offer of the day, category discount, manual-discount ceiling | PRC-04 → PRC-08 |
| From the branch | Pause an item when an ingredient runs out; timed discount on an item | CAT-06, PRC-10 |

**Open decisions:** D-01 stock level · D-07 waste · D-24 central warehouse.
